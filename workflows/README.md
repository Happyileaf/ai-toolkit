# Workflows

本目录用于存放大模型相关的工作流配置。

## 目录结构

- `index.md` - 工作流统一索引
- `ui-prototype-restore-loop/` - 前端 UI 原型还原闭环工作流（入口：`WORKFLOW.md`）
- `ui-design-spec-refactor-loop/` - 基于设计规范的前端 UI 重构闭环工作流（入口：`WORKFLOW.md`）
- `ui-design-spec-ground-up-refactor-loop/` - 基于设计规范、去锚点的前端 UI 激进重构闭环工作流（入口：`WORKFLOW.md`）

## 工作流索引

详见 [`index.md`](./index.md)。

## 工作流格式

每个工作流应包含以下内容：
- 工作流名称
- 工作流描述
- 工作流步骤
- 步骤间的依赖关系
- 使用示例
