# Skill 版本管理规范

> Librarian Agent 版本发布与管理的依据

## 语义化版本规范

遵循 [Semantic Versioning 2.0.0](https://semver.org/)

### 版本格式

```
MAJOR.MINOR.PATCH

例如: 1.0.0, 1.2.3, 2.0.0
```

### 版本变更规则

| 变更类型 | 版本变更 | 示例 |
|----------|----------|------|
| **MAJOR** | 破坏性变更、接口重构 | 1.0.0 → 2.0.0 |
| **MINOR** | 新功能、向后兼容的增强 | 1.0.0 → 1.1.0 |
| **PATCH** | Bug 修复、文档补充 | 1.0.0 → 1.0.1 |

---

## 版本变更判定

### MAJOR (+1.0.0)

| 条件 | 说明 |
|------|------|
| 输入接口变更 | 必填参数变化、参数类型变化 |
| 输出接口变更 | 输出格式变化、字段移除 |
| 依赖降级 | 原有依赖不再支持 |
| 核心行为变更 | 核心功能逻辑变化 |

### MINOR (+0.1.0)

| 条件 | 说明 |
|------|------|
| 新增功能 | 新增可选参数、新输出字段 |
| 性能优化 | 执行效率提升 |
| 依赖升级 | 新增可选依赖 |
| 文档增强 | 使用说明改进 |

### PATCH (+0.0.1)

| 条件 | 说明 |
|------|------|
| Bug 修复 | 修复已知问题 |
| 文档修正 | 示例补充、说明完善 |
| 小优化 | 不影响功能的调整 |

## 版本生命周期

```
draft → beta → active → deprecated → retired
```

### 各阶段定义

| 状态 | 说明 | 时间限制 |
|------|------|----------|
| `draft` | 开发中，不可用于生产 | 无限制 |
| `beta` | 测试阶段，可试用 | 最多 30 天 |
| `active` | 正常使用 | 持续 |
| `deprecated` | 已弃用，建议迁移 | 公告后 14 天 |
| `retired` | 已退役，不可使用 | 永久 |

---

## 版本保留策略

| 类型 | 保留规则 |
|------|----------|
| MAJOR 版本 | 保留最近 3 个大版本 |
| MINOR 版本 | 保留最近 2 个小版本 |
| PATCH 版本 | 保留所有 |

**示例**: Skill v2.1.3

```
保留版本:
- v2.1.3 (current)
- v2.1.2
- v2.1.1
- v2.1.0
- v2.0.x (所有 PATCH)
- v1.x.x (最后 2 个 MINOR)

可清理版本:
- v1.0.x (超过保留期)
```

## 版本发布节奏

| 类型 | 发布窗口 | 公告周期 |
|------|----------|----------|
| 正常发布 | 周二、周四 | 提前 2 天公告 |
| 紧急发布 | 立即 | 同步公告 |
| MAJOR 发布 | 周二 | 提前 2 周公告 |

## 版本标签

| 标签 | 说明 |
|------|------|
| `latest` | 最新稳定版本 |
| `stable` | 稳定版本（非 latest） |
| `beta` | 测试版本 |
| `deprecated` | 已弃用版本 |
| `security-fix` | 安全修复版本 |

- 无

## 版本兼容性检查

### 向后兼容性

| 检查项 | 标准 |
|------|------|
| 输入参数 | 新增参数必须可选 |
| 输出格式 | 新增字段不影响原有字段解析 |
| 依赖变更 | 依赖升级不破坏现有调用 |

### 破坏性变更处理

| 处理方式 | 说明 |
|----------|------|
| 提前公告 | MAJOR 版本提前 2 周公告 |
| 迁移指南 | 提供详细迁移步骤 |
| 兼容期 | 保留旧版本 2 个大版本周期 |
| 自动迁移 | 提供迁移脚本（如有） |

## 版本回滚

### 回滚条件

| 条件 | 说明 |
|------|------|
| 新版本严重 Bug | 影响正常使用 |
| 用户强烈反馈 | 大量用户投诉 |
| 安全问题 | 新引入安全风险 |

### 回滚流程

```
1. 确认回滚必要性
2. 发布回滚公告
3. 更新 index.md 指向旧版本
4. 标记新版本为 beta/deprecated
5. 记录回滚原因
```
