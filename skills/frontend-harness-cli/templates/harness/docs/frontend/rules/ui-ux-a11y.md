# UI/UX 与可访问性规则

本文件适用于页面结构、组件交互、样式与可访问性相关改动。

## 1. 触发条件

- 新增或修改页面、弹窗、表单、导航、按钮、列表等交互。
- 修改视觉样式、主题变量、动效或布局系统。
- 涉及可访问性（键盘流、语义标签、替代文本、焦点管理）。

## 2. 核心门禁

1. **响应式可用**：桌面与移动关键断点可正常使用。
2. **键盘可达**：关键操作无需鼠标可完成。
3. **语义完整**：表单、按钮、导航、标题层级语义正确。
4. **状态可感知**：加载态、空态、错误态、禁用态对用户可见。
5. **设计一致性**：优先 design token/CSS 变量，不散落魔法值。

## 3. 具体要求

- 非装饰性图片必须提供可读 `alt`。
- 弹窗/抽屉打开后焦点管理清晰，关闭后焦点回归。
- 表单字段错误必须给出明确文本提示，不仅靠颜色区分。
- 动效不能阻碍核心操作，不应造成可用性退化。
- 保持已有设计系统和组件 API 风格一致。

## 4. 验收证据

- 关键页面包含桌面+移动截图或验证记录。
- 合同中列出 a11y 人工检查项并完成打勾。
- QA 报告记录至少 1 个键盘流验证结论。
