# 规划功能

## 流程

1. 调用 `planner` 智能体。
2. `planner` 会：
   - 自动归纳假设/歧义/取舍/范围外事项，不反复向用户提问。
   - 调研相关代码与现有设计模式。
   - 产出可机器验证的验收标准。
   - 明确响应式、可访问性、性能预算和关键交互流。
   - 在 `.harness/docs/specs/<feature-name>.md` 输出结构化 spec。
3. 输出 spec 路径、关键假设和风险。

**不要开始实现。** 本命令只产出规划与规格。
