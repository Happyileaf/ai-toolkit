# 发布状态与门槛（Publication Criteria）

## 1. 状态定义

| 状态 | 含义 | 后续动作 |
|---|---|---|
| Ready for Review | 已完成适用审查，未发现未处理的阻断项 | 可交给用户人工审核 |
| Needs Revision | 仍有需要修改或确认的问题 | 修改后重新审查 |
| Blocked | 存在不可接受风险，或无法安全处理关键内容 | 不建议进入发布审核 |
| Incomplete | 输入未能完整读取/理解，或审查范围存在重大缺口 | 补齐资料或限制发布范围后重新审查 |

Ready for Review 只代表模型已完成当前范围内的审查，不代表企业授权、法律许可或绝对安全，也不等于可以自动发布。

## 2. 判定原则

- 有未处理的 Critical Finding：Blocked。
- 有未处理的 High Finding，且其公开会暴露敏感信息或利用风险：Blocked 或 Needs Revision；不得 Ready for Review。
- 有尚未解决且影响内容准确性或披露边界的确认事项：Needs Revision。
- 最终资料存在重要未读取区域：Incomplete。
- A、B 的最终产物完成复审，且不存在未处理的阻断风险和重大缺口：可标记 Ready for Review。
- C 是审计模式，不代表被审计文档已通过；应说明“审计结论”，并根据原始资料风险和完整性给出状态。

## 3. 人工审核

所有产物都必须由用户在发布前人工审核。若涉及企业机密、客户信息、未公开安全漏洞、第三方数据或组织内部披露制度，用户还应遵循所属组织的授权和披露流程。

## 4. 不能作出的承诺

不得使用“绝对安全”“保证不会泄露”“已经获得公开授权”“可以直接发布，无需审核”等表述。应使用可核验的表述，例如“在当前可读取资料范围内，未发现尚未处理的已知敏感信息”或“当前状态为 Ready for Review，仍需人工审核和必要的组织授权”。
