# Repository Preparation

1. Confirm the repository root and identify the active workspace.
2. Inspect the current branch, working-tree status, and relevant remotes.
3. Determine whether the current branch is synchronized with its upstream when that information is available.
4. Identify existing documentation under `docs/analysis/` and any user-authored files that could be affected.
5. Do not switch branches, pull, reset, stash, clean, or overwrite changes without explicit permission.
6. If the working tree contains uncommitted changes, preserve them. Avoid touching unrelated files.
7. Record the repository state and any constraints before scanning.

If repository metadata or remote status cannot be inspected, state that limitation and continue only with safe, read-only analysis.
