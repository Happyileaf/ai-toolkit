# 图示规范

- 将可编辑的 Mermaid 源文件以 `.mmd` 格式保存在 `docs/analysis/diagrams/` 下。
- 使用 architecture diagram 展示组件、分层、依赖和外部边界。
- 使用 sequence diagram 展示按时间排序的交互，使用 flowchart 展示判断和分支逻辑。
- 图示中的名称必须与文档保持一致。
- 使用有意义的动作、数据或协议描述连线。
- 每张图聚焦一个主题；无关内容应拆分为多张图。
- 不得绘制源代码证据不支持的依赖、调用或执行顺序。
- 在相关 Markdown 文档中添加简短的图示说明。
- 除非能实质性解释复杂行为，否则避免绘制 code-level diagram。
