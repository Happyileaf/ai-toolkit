# 系统概览

## 目标与范围
说明系统的用途、解决的问题，以及包含和不包含的内容。

## 用户与调用方
识别用户群体、调用系统或使用该系统的开发者。

## 主要能力
描述主要能力，并关联到对应实现。

## 运行环境
说明系统如何启动、运行位置及主要运行时依赖。

## 核心概念
介绍理解系统实现所必需的核心概念。

## 系统工作方式
说明主要组件如何协作完成一次典型执行。

## 重要入口
列出主要入口及其职责。

## 外部依赖
概述重要的外部服务、平台和 packages。

## 延伸阅读
链接到架构、流程、术语表和相关源码区域。

## 证据与限制
记录重要证据、不确定性和分析限制。
