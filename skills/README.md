# Skills

本目录用于存放大模型相关的技能配置。

## 目录结构

- `index.md` - 技能统一索引
- `agent-browser-0.2.0/` - 浏览器自动化技能
- `export-bundle/` - 打包 rules/skills/workflows 的分发技能
- `ui-gap-audit/` - UI 差距审计技能
- `ui-restore-implementation/` - UI 还原实现技能
- `ui-prototype-restore/` - UI 原型还原端到端技能
- `repository-documentation/` - 全量分析代码仓库并生成技术文档的技能
- `git-branch-name-generator/` - 配置驱动生成 Git 分支名称的技能
- `technical-content-sanitizer/` - 识别研发资料敏感信息，完成脱敏、审查与公开化重构

## 技能索引

详见 [`index.md`](./index.md)。

## 技能格式

每个技能应包含以下内容：
- 技能名称
- 技能描述
- 技能触发条件
- 技能执行逻辑
- 使用示例
